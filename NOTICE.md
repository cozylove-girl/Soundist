# Soundist Android Notices

## Project origin

Soundist is a substantial derivative development based on
[Moodist](https://github.com/remvze/moodist). It is not an official Moodist
release. The original Moodist software and Soundist application code are
distributed under the repository `LICENSE` unless a file states otherwise.

## Moodist ambient sounds

Soundist includes 84 ambient sound files inherited unchanged from Moodist.
Moodist's public notice states that third-party sounds are covered by either
the Pixabay Content License or Creative Commons CC0 1.0. Moodist does not
publish a per-file mapping between those licenses, so Soundist preserves the
same aggregate notice instead of labelling every inherited file as CC0.

The upstream commit, license, asset notice and SHA-256 comparison are archived
under `tools/license-snapshots/moodist-ambient-2026-08-24/`.

## Other audio assets

The application also contains separately licensed open music and CC0 VSCO 2
CE instrument samples. Complete source, author, license and hash records are
maintained in:
